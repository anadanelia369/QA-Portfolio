Testing is not only verification. It is exploration. I'm drawn to exploratory approaches and the tour-based ideas of James Whittaker.

autism.ge — Notable Findings
Critical·BUG-04·Payment Processing
WordPress Backend Returns Error Despite Successful Payment
Payment completes successfully via Visa and Google Pay — confirmation email delivered with correct subscription details. Simultaneously, WordPress backend displays an error on the post-redirect page. Business risk: donors may believe payment failed and attempt to pay again, risking duplicate charges. Documented with screen recording of full payment flow.
Critical·BUG-01·Authentication
Missing "Forgot Password" Functionality
No password recovery mechanism exists on the login page. Users who forget their password have no self-service way to regain account access — permanently locked out without support intervention.
Critical·BUG-03·Subscriptions
Active Subscriptions Not Displaying on Subscriptions Page
Despite confirmed active subscription, the Subscriptions page appears empty. Users cannot verify or manage their own recurring donations — high risk of confusion and unintended cancellations.
High·BUG-05·Session Management
Auth Page Accessible After Logout
After clicking Logout, the authentication page remains accessible in a state suggesting the session was not properly invalidated. Potential security concern — backend session verification needed.
High·BUG-08·UX
"Registration" Button Shown to Already-Authorized Users
The payment flow displays a "Registration" button for users who are already logged in. Misleading UX — implies account creation is required when it is not. Label should read "Payment" for authorized users.
ODIN P2P — Notable Findings
Critical·ODIN-995·Mobile UI
Time Picker Crash on Chat Screen
Tapping the time picker on the chat screen causes the app to crash completely. Reproducible 100% of the time on Android 14 / Realme 10. Users lose active chat session and must restart the app.
High·ODIN-974·Navigation
Phone Country Code Auto-Changes on Back Navigation
When user navigates back from a screen, the phone country code field resets to a different value without user input. Affects international users — incorrect code submitted silently.
High·ODIN-1013·Navigation
System Back Button Breaks Trip Flow
Pressing the system back button during trip creation breaks the flow — user is redirected incorrectly and trip data is lost. Expected: back navigation preserves state.
🔒 All bugs are fully documented with reproduction steps, severity classification, and environment details. Following the completion of a 6-month intensive UAT internship, screenshots remain the property of the company and are not publicly available.
GPI Holding — Notable Findings
High · Security·GPI-ANN-13
Autofill Returns Stranger's Personal Data
Chrome autofill populates personal data fields with another user's information from a previous session. A complete stranger's name, ID, and contact details appear pre-filled. Critical data privacy violation on a live insurance platform.
High · Security·GPI-ANN-11
Invalid Citizenship + Document Combination Accepted
Afghan citizenship combined with a Georgian ID number passes validation without error. The system accepts an impossible document combination — bypassing core identity verification logic.
High·GPI-ANN-12·BVA
Calendar Allows 366-Day Insurance Period
Boundary value testing revealed the calendar accepts a 366-day period for a non-leap year — one day beyond the legal maximum. Core business validation logic not enforced.

GET /products?limit=3 returns 20 products instead of 3
pm.test("Status code is 200", function () {
  pm.response.to.have.status(200);
});

pm.test("Exactly 3 products (limit=3)", function () {
  const json = pm.response.json();
  pm.expect(json.length).to.equal(3);
});

console.log("Products returned: "
  + pm.response.json().length);
