Testing is not only verification. It is exploration. I'm drawn to exploratory approaches and the tour-based ideas of James Whittaker.

autism.ge — Notable Findings
Critical·BUG-04·Payment Processing

WordPress Backend Returns Error Despite Successful Payment

Payment completes successfully via Visa and Google Pay, and a confirmation email is delivered with the expected subscription details. At the same time, the post-redirect flow displays an error. Business risk: donors may believe payment failed and attempt to pay again. Documented with a screen recording of the full payment flow.

Critical·BUG-01·Authentication

Missing "Forgot Password" Functionality

No password-recovery mechanism exists on the login page. Users who forget their password have no self-service way to regain access and must rely on support intervention.

Critical·BUG-03·Subscriptions

Active Subscriptions Not Displaying on Subscriptions Page

Despite a confirmed active subscription, the Subscriptions page appears empty. Users cannot verify or manage recurring donations, creating confusion around account state and subscription management.

High·BUG-05·Session Management

Auth Page Accessible After Logout

After Logout, the authentication page remains accessible in a state suggesting that session invalidation may be incomplete. Backend session verification is required to confirm the security impact.

High·BUG-08·UX

"Registration" Button Shown to Already-Authorized Users

The payment flow displays a "Registration" button for users who are already logged in. The label implies account creation is required when it is not, creating avoidable friction and confusion.

Critical·BUG-06·Authentication

Password Reset and Registration Block New Users Before Payment

Password reset and registration flows fail, preventing new users from reaching the donation/payment step. Payment processing was independently verified as functional, isolating the observed failure to the authentication layer. Documented with screen recordings.

High·BUG-07·Architecture

Registration Tightly Coupled to Donation Flow

Registration exists as part of the donation flow rather than as an independent function. Decoupling the flows would reduce the blast radius of future donation-flow changes and allow account creation independently.

ODIN P2P — Notable Findings
Critical·ODIN-995·Mobile UI

Time Picker Crash on Chat Screen

Tapping the time picker on the chat screen causes the app to crash. Reproducible on Android 14 / Realme 10. Users lose the active chat session and must restart the app.

High·ODIN-974·Navigation

Phone Country Code Auto-Changes on Back Navigation

When the user navigates back from a screen, the phone country-code field resets to a different value without user input. This can affect international users and silently alter submitted data.

High·ODIN-1013·Navigation

System Back Button Breaks Trip Flow

Pressing the system back button during trip creation breaks the flow and can result in incorrect redirection and lost trip data. Expected behavior: preserve relevant state during back navigation.

GPI Holding — Notable Findings
High·Security / Privacy·GPI-ANN-13

Browser Autofill Returns Another User's Personal Data

During testing, Chrome autofill populated personal-data fields with another user's information from a previous session. The observation was treated as a privacy/security finding and requires environment and application-level investigation.

High·Security·GPI-ANN-11

Invalid Citizenship + Document Combination Accepted

An Afghan citizenship value combined with a Georgian ID number passes validation without an error. The system accepts an inconsistent identity-document combination, indicating a validation gap.

High·GPI-ANN-12·BVA

Calendar Allows 366-Day Insurance Period

Boundary-value testing revealed that the calendar accepts a 366-day insurance period for a non-leap year — one day beyond the intended boundary.
